## 📖 About

**Survival of the Brightest 2** is an educational 2D survival game designed to help teach kids in upper elementary to early middle school ages (typically ages 9-13) about:
- 🧮 **Mathematics** - Problem-solving and calculations
- 📚 **General Knowledge** - Broad educational topics
- 🏛️ **History** - Historical facts and events
- 🔬 **Science** - Scientific concepts and principles

This game was created for the **2023 TSA (Technology Student Association) State Competition**, where our team proudly placed in the **top 10 in Texas**.

## 🎮 Gameplay

In Survival of the Brightest 2, players must use their knowledge across multiple subjects to survive and progress through challenges. The game combines educational content with engaging survival mechanics, making learning fun and interactive.

### Key Features
- ✨ Educational content across multiple subjects
- 🎯 Challenge-based progression system
- 🏆 Achievement and scoring system
- 🎨 Engaging 2D graphics
- 🎵 Immersive sound design
- 👥 Suitable for classroom or individual play
